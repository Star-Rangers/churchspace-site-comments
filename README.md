# Church Space — Site Comments

This repo has no code — it exists purely to host the [GitHub Discussions](https://docs.github.com/en/discussions) that power reader comments on *Church Space*, the devotional overlay of [*Fian Ilchruinne*](https://github.com/dermot-r-cochran/star-rangers) (the work formerly titled *Star Rangers*), deployed at church-space.site (church-space.online redirects there). The Church Space storyline thread carries explicit Christian and evangelical themes not part of the main published canon, and is tier-gated to the contemplative editions: absent from the other domains rather than private.

Comments on the site are powered by [giscus](https://giscus.app), which maps each page of that thread to a Discussion in this repo, on whichever domain renders it. The threads live in this repo's [Discussions](https://github.com/Star-Rangers/churchspace-site-comments/discussions). Looking for the story itself, or the site's source code? Head to **[dermot-r-cochran/star-rangers](https://github.com/dermot-r-cochran/star-rangers)** or church-space.site.
