# Church Space — Site Comments

This repo has no code — it exists purely to host the [GitHub Discussions](https://docs.github.com/en/discussions) that power reader comments on *Church Space*, the devotional overlay of [*Fian Ilchruinne*](https://github.com/dermot-r-cochran/star-rangers) (the work formerly titled *Star Rangers*), deployed at church-space.site (church-space.online redirects there). The Church Space storyline thread carries explicit Christian and evangelical themes not part of the main published canon, and is tier-gated to the contemplative editions: absent from the other domains rather than private.

Comments on the site are powered by [giscus](https://giscus.app), which maps each page of that thread to a Discussion in this repo, on whichever domain renders it. The threads live in this repo's [Discussions](https://github.com/Star-Rangers/churchspace-site-comments/discussions); the [welcome post](https://github.com/Star-Rangers/churchspace-site-comments/discussions/4) is the place to start. Only the thread's own pages post here: the main-sequence chapters, characters and lore that church-space.site also carries post to the shared board, [sciencefiction-site-comments](https://github.com/Star-Rangers/sciencefiction-site-comments), so one chapter has one conversation wherever it appears. Looking for the story itself, or the site's source code? Head to **[dermot-r-cochran/star-rangers](https://github.com/dermot-r-cochran/star-rangers)** or church-space.site.

## Taking part

The usual way in is from the site itself. Each page of the thread that takes comments ends in a *Discussion* heading, and *Show discussion* under it opens that page's thread with a box to write in. Reading needs nothing; posting needs a GitHub account, because every comment is kept in a GitHub Discussion. A page's thread is created the first time someone comments on it, so a page with no thread here is one nobody has commented on yet.

Comments are public as soon as they are posted. As the note on each page says, they are read after they are posted and anything unsuitable is removed.
